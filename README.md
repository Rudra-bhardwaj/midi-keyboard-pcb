# midi keyboard
midi keyboard is a musical synthesizer which is an electronic musical instrument that generates and modifies audio signals to create unique sounds

 ## features
1)EC11 Rotary Encoders

2)SK6812 MINI-E Neopixels

3)Bourns Slide Potentiometers

4)Kailh Choc Low-Profile Switches

5)and some copper pads to play music!
